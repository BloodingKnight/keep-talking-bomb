加入一场拆弹

每个人用自己的一台设备（手机 / 平板 / 电脑）打开本页面。拆弹者只能看到炸弹， 专家只能看到手册，所有沟通靠你们自己当面进行。

📖 新手教程
怎么玩？
  1. 一人当拆弹者：负责看炸弹、动手操作（只能看炸弹，没有手册）。
  2. 其他人当专家：只有手册和炸弹外壳信息（序列号、电池、指示灯、端口）。
  3. 需要 3 人以上的时候，可以再选「盲眼观察员（只有半本手册）」「静默操作员（能操作但不能说话）」。
  4. 拆弹者把看到的东西念出来，专家查表告诉他按什么、剪哪根。
  5. 失误过多或者倒计时归零，炸弹爆炸。
