5 分钟看懂怎么玩

这是一个信息不对称的合作拆弹游戏：一个人只能看到炸弹，其他人只能看到手册， 剩下的全靠你们自己沟通。倒计时归零或者失误达到上限，炸弹就炸了。

① 怎么开始 ② 所有角色 ③ 推荐配置 ④ 沟通链路 ⑤ 18 个模块 ⑥ 一个人也能试玩 ⑦ 实用技巧
没有对错，只有说清楚。这个游戏里沟通比聪明重要：把看到的东西具体地念出来， 问问题要问到点上。

① 怎么开始

  1. 房主打开 http://<这台电脑的IP>:3210，点「加入 / 新建」建房，把房间号或邀请链接发给朋友。
  2. 每个人用自己的设备打开那个链接，填昵称、加入同一个房间号。
  3. 准备区里挑角色（或让房主点一个推荐预设一键分好）；房主选难度，然后点「开始拆弹」。
  4. 倒计时开始后：看得到炸弹的人描述，有手册的人查表，能动手的人操作。
  5. 所有模块拆完 = 成功；失误到上限或时间归零 = 爆炸。
语音不在游戏里 —— 请当面说话、或者开你自己的语音软件。游戏只提供文字频道和手势信号， 给"不能说话"的角色用。

② 所有角色（9 个座位）

每个角色都是一块"残缺"：屏幕内容、能不能操作、能不能说话，各不相同。

A. 基础三件套（最常用）

🧰拆弹者
看得到炸弹 · 能操作 · 能说话
  • 屏幕上只有炸弹：模块、倒计时、失误灯
  • 没有手册：所以你必须把看到的一切念出来
  • 念什么：颜色、顺序、字母数字、闪烁的长短、按钮上的字
📖专家
看不到炸弹 · 有完整手册 · 能说话
  • 手上是手册 + 炸弹外壳信息（序列号 / 电池 / 指示灯 / 端口）
  • 要主动问清外壳信息，再查表得出可执行的指令
  • 把结论说成一句话：「剪从上往下第 3 根」
🙈盲眼观察员
看不到炸弹 · 只有半本手册 · 能说话
  • 和专家一样有手册，但只有一部分条目（座位固定）
  • 玩法：先报"我这边有哪些行"，再和其他专家互相补全
  • 适合 3~4 人，故意制造一点"信息拼图"
🤐静默操作员
看得到炸弹 · 能操作 · 不能说话
  • 和拆弹者一样能看能动手，但只能用文字频道打字
  • 适合想体验"手忙脚乱打字"的玩家

B. 三人经典：不看 / 不听 / 不说（参考《BOMBANANA!》的三不猴）

准备区点「三人经典（不看不听不说）」预设即可一键分配。三种感官各缺一个，必须"转述"。

🙈盲操猴
只有轮廓 · 唯一能动手的人 · 没有倒计时
  • 屏幕是黑的，只有模块的白色轮廓：颜色、数字、文字全看不见
  • 但他能点、能操作 —— 全靠队友喊指令盲操作
  • 时间也看不到，要队友报"还剩多久"
🙉聋桥猴
看得见炸弹和信号 · 听不见 · 能说话
  • 唯一同时看得见"炸弹颜色数字"和"队友手势信号"的人
  • 他是沟通桥梁：把哑手册猴的信号翻译成口头指令喊给盲操猴
  • 也能替盲操猴报时（他看得到倒计时）
🙊哑手册猴
有手册 · 不能说话
  • 手册在他手上，但他只能点手势信号（1 / 2 / 3 / 🔴 红 / ✅ 对 …）或用文字频道
  • 请自觉闭嘴，把信息"比划"给聋桥猴

C. 还有两个专家座位

人数多的时候会出现专家 II / 专家 III，拿的是手册的另外几份 —— 手册被拆开，必须互相念。

③ 推荐配置

人数推荐组合体验
2 人拆弹者 + 专家最纯粹：你念，我查表
3 人盲操猴 + 聋桥猴 + 哑手册猴（三人经典预设）最欢乐：三种残缺，必须"中间商式"转述
3 人（传统）拆弹者 + 专家 + 盲眼观察员手册被拆一半，需要拼信息
4~5 人盲操 + 聋桥 + 两个哑手册两个半本手册，两个人抢着比划
6 人拆弹者 + 5 个专家座位人多嘴杂，适合派对
一个"动手座位"（拆弹者 / 静默操作员 / 盲操猴）只能有一个人；其余都是专家座位。

④ 沟通链路长什么样

标准局（拆弹者 + 专家）

拆弹者：屏幕上 4 根线，从上到下是 红、蓝（带白条纹）、黄、黑 ↓ 说给专家听 专家：（查手册）有黄线且序列号末位是奇数 → 剪第 3 根 ↓ 下指令 拆弹者：剪第 3 根 ✅

三人经典（盲操 / 聋桥 / 哑手册）

盲操猴：我屏幕上只有一个单词「VECTOR」（他看不到别的） ↓ 喊出来 聋桥猴：（听得到）把单词转给哑手册猴看 ↓ 哑手册猴：（查手册）V = ···—，点「信号：3」 ↓ 手势/信号（他不能说话） 聋桥猴：看到信号「3」→ 结合手册得知 V 是 ···— ↓ 口头喊 盲操猴：敲 · · · — → 发送 ✅
最经典的翻车现场：聋桥猴听不见却一直等回应、哑手册猴比划没人看、 盲操猴看不见只能瞎点。所以请记住：聋桥猴要主动看屏幕上的信号面板。

⑤ 18 个模块速查

每个模块都是"炸弹上看到一半 + 手册上看到另一半"。下面是每类模块的关键问法。

模块看得到炸弹的人要念什么手册那边给什么
🪢 线缆几根线、从上到下什么颜色、有没有条纹按顺序判断的表 → 剪第几根
🧵 复杂线路每根线的颜色、条纹、★、LED 亮不亮、线上的字母字母含义表（C 剪 / D 不剪 / S / P / B）
🔘 按钮按钮颜色 + 上面的字；按住后光条什么颜色轻按还是按住；光条颜色 → 松手的秒数
⌨️ 符号键盘键盘上 4 个符号长什么样三列符号，只有一列全包含 → 按该列顺序
🚦 闪光序列依次闪了哪些颜色（按顺序念）闪烁颜色 → 要按的按钮（还有元音/失误分行）
🎇 双序列闪光第一段（慢）闪什么、第二段（快）闪什么表 A / 表 B 两张换算表

🔠 字母键盘面板上那串（移位过的）字母移位量 → 还原成口令

炸弹外壳信息（专家必问）

  • 序列号：是否含元音字母（A/E/I/O/U）、末位是奇数还是偶数
  • 电池：几个
  • 指示灯：哪些亮着（SIG / CAR / FRK …）
  • 端口：Serial / Parallel / Stereo RCA / DVI-D / USB / RJ-45
  • 失误次数：有些换算表要按当前失误数选列

⑥ 一个人也能试玩

打开管理入口（服务启动时终端会打印带令牌的地址）：

  • 🎭 角色视角：生成一颗完整炸弹，然后点上面的角色按钮，就能单独看到那个角色屏幕上的全部内容 —— 包括盲操猴那种"只有白色轮廓"的画面。想单人演一遍，就在几个角色之间来回切。
  • 🧪 模块验题：只想练某个模块？选「模块 + 等级」，左边是题目、右边是同一道题的手册，还能直接点着玩。
  • 一键全量自检：18 个模块 × 5 个等级全部生成一遍，检查题目和手册是否有问题。
房主在游戏准备区也有一个「模块测试台」按钮，功能一样，不用开管理入口。

⑦ 实用技巧

给看得到炸弹的人

  • 说"具体信息"而不是"感觉"：不说"好像有根蓝线"，说"从上往下第 2 根是蓝的，带白条纹"。
  • 按顺序念：从左到右、从上到下，别跳。
  • 先报数量：「一共 4 根线」，专家才好定位。
  • 模块闪灯/闪颜色时，念出节奏：「长、短、短、长」。

给查手册的人

  • 先问清外壳信息（序列号元音/末位、电池、指示灯、端口），很多表都靠这些选行选列。
  • 把指令说成可执行的一句话：「剪从上往下第 3 根」，而不是「查表第 5 行」。
  • 一次只让拆弹者做一件事，做完再给下一条。

给三人经典配置

  • 聋桥猴是队长：主动盯信号面板，别等别人"说"给你。
  • 哑手册猴：信号按钮有 1/2/3/4、颜色、上下左右、"对/错"，够表达大部分信息；复杂的用文字频道。
  • 盲操猴：报告"我点了什么、现在什么状态"，让队友确认；失误了要立刻说。
  • 约定一套手势暗号（比如「✅ 对」= 可以按，「❌ 错」= 停），会快很多。
