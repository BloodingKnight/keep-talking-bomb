下载（Windows） 源码 / 玩法说明

Windows 直接下安装包；macOS / Linux 用 ./start.sh（需要 Node 18+）

1三分钟开一局

  1. 房主在自己电脑上打开游戏（安装包 / 绿色版 / node server/server.js）
  2. 大厅里会出现一个邀请二维码和局域网地址
  3. 朋友用手机扫描 / 打开地址 → 选角色 → 房主点「开始拆弹」

不在同一个 Wi-Fi？

  1. 在房主电脑上运行 node tools/share.mjs
  2. 它会打印一个公网 https://… 地址
  3. 把这个地址发给朋友，**二维码会自动变成公网地址**
这个游戏需要一个正在运行的服务端（房间、倒计时、判定都在服务端，答案永远不下发到玩家浏览器）。 所以它没法直接放在纯静态托管上玩 —— 静态托管只能放这个介绍页。

3常见问题

提示「node 被拦截 / 端口被占」？
换 3211 之后的端口会自动尝试；杀软如果拦了内置的 node.exe，把它加入白名单，或者改用绿色版（里面是 Node 官方原版 node.exe，签名完好）。

能不能做成微信小程序？
目前不行：个人主体选不了「游戏」类目（游戏类目要企业主体 + 版号），小程序还不允许访问局域网 IP、也没有 SSE。 想分享最快的办法是上面那条隧道地址，微信里直接点开就是普通网页。

能不能放到 B站 Toy / 静态托管？
Toy 这类平台发布的是「网页作品」，适合单机互动；本作是多人 + 实时同步，需要服务端。 除非改造成浏览器内 P2P（WebRTC），否则放上去只能玩单机部分。

数据安全吗？
房间、答案、计时全在你自己的机器上，不经过任何第三方；管理入口带一次性令牌。 用隧道时流量会经过隧道服务商（cloudflared / ngrok / localtunnel）。
